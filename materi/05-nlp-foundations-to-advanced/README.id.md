# Fase 5: NLP, dari Dasar hingga Mahir

> Bahasa adalah antarmuka menuju kecerdasan. Kuasai setiap lapisannya.

## Mulai fase ini di GitHub

**Prasyarat:** Fase 2 Pelajaran 14, Naive Bayes. Python 3.11+ sudah cukup untuk pelajaran pertama.

**Pelajaran pertama:** [Pemrosesan Teks](01-text-processing/)

Jalankan perintah ini dari root repositori:

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

Simpan perintah, kode keluar, daftar token, hasil stemming, lemma, dan satu contoh ketika stemming menghilangkan makna tetapi lemmatisasi mempertahankannya.

**Tindakan berikutnya:** Tambahkan satu kalimat dengan tanda baca dan kata kerja tidak beraturan, periksa hasilnya, lalu lanjut ke [Bag of Words dan TF-IDF](02-bag-of-words-tfidf/).
