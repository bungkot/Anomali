# Fase 1: Dasar-Dasar Matematika

> Intuisi di balik setiap algoritma AI, melalui kode, bukan buku teks.

## Mulai fase ini di GitHub

**Prasyarat:** Selesaikan Fase 0, atau pastikan Python 3.11+ dan Git berjalan
dari direktori akar repositori.

**Pelajaran pertama:** [Intuisi Aljabar Linear](01-linear-algebra-intuition/)

Jalankan perintah ini dari direktori akar repositori:

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

Simpan perintahnya, kode keluar, keluaran vektor ternormalisasi, residual
proyeksi, dan satu kalimat yang menjelaskan mengapa perkalian matriks-vektor
merupakan lapisan jaringan saraf.

**Tindakan berikutnya:** Ubah satu vektor input, prediksi hasilnya, jalankan
lagi, lalu lanjut ke [Vektor, Matriks, dan Operasi](02-vectors-matrices-operations/).

Jelajahi [daftar lengkap pelajaran Fase 1](../../docs/README.md#phase-1) atau
[peta jalan lintas fase](../../ROADMAP.md).
