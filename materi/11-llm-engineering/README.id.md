# Fase 11: Rekayasa LLM

> Manfaatkan LLM dalam aplikasi produksi.

## Mulai fase ini di GitHub

**Prasyarat:** Fase 10 Pelajaran 01 sampai 05, atau pengetahuan yang setara tentang
tokenisasi, pipeline data, pra-pelatihan, dan penskalaan.

**Pelajaran pertama:** [Prompt Engineering](01-prompt-engineering/)

Jalankan perintah ini dari root repositori:

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

Simpan perintah, kode keluar, metadata prompt yang dihasilkan, hasil pengujian, dan satu
perubahan prompt beserta perbedaan keluaran yang ditimbulkannya. Demo ini menggunakan
respons model simulasi dan tidak memerlukan kunci API.

**Tindakan berikutnya:** Jelaskan variabel prompt mana yang mengubah perilaku dan mengapa, lalu
lanjutkan ke [Few-Shot, Chain-of-Thought dan Tree-of-Thought](02-few-shot-cot/).
