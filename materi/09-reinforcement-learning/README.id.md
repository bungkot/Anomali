# Fase 9: Reinforcement Learning

> Agen yang belajar dengan melakukan. Landasan dari RLHF.

## Mulai fase ini di GitHub

**Prasyarat:** Probabilitas dan distribusi Fase 1, ditambah Pelajaran 01 Fase 2
untuk taksonomi ML.

**Pelajaran pertama:** [MDP, States, Actions and Rewards](01-mdps-states-actions-rewards/)

Jalankan perintah ini dari akar repositori:

```bash
python3 phases/09-reinforcement-learning/01-mdps-states-actions-rewards/code/main.py
```

Simpan perintah, kode keluar, hasil random dan greedy, grid nilai, dan satu
kalimat yang menghubungkan kualitas kebijakan dengan ekspektasi return.

**Tindakan berikutnya:** Ubah faktor diskonto, prediksi pergeseran nilai, lalu
lanjutkan ke [Dynamic Programming](02-dynamic-programming/).
