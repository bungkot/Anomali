# Fase 10: LLM dari Awal

> Bangun, latih, dan pahami model bahasa besar.

## Mulai fase ini di GitHub

**Prasyarat:** Fase 5 Dasar-Dasar NLP. Fase 7 Transformers sangat
direkomendasikan sebelum pelajaran membangun model.

**Pelajaran pertama:** [Tokenizer](01-tokenizers/)

Jalankan perintah ini dari akar repositori:

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

Simpan perintah, kode keluar, hasil putaran bolak-balik encode/decode, jumlah
penggabungan yang dipelajari, dan rasio kompresi. `tiktoken` adalah perbandingan
opsional.

**Tindakan berikutnya:** Tambahkan kata yang belum pernah dilihat oleh korpus
mini, periksa potongan-potongannya, lalu lanjut ke
[Membangun Tokenizer dari Awal](02-building-a-tokenizer/).

Lihat [daftar lengkap pelajaran Fase 10](../../docs/README.md#phase-10) atau
[peta jalan lintas fase](../../ROADMAP.md).
