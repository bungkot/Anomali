# Fase 3: Inti Deep Learning

> Jaringan saraf dari prinsip pertama. Tidak ada framework sebelum Anda membangunnya sendiri.

## Mulai fase ini di GitHub

**Prasyarat:** Fase 1 Intuisi Aljabar Linear. Fase 2 disarankan
untuk kosakata evaluasi model.

**Pelajaran pertama:** [Perceptron](01-the-perceptron/)

Jalankan perintah ini dari root repositori:

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

Simpan perintah, kode keluar, hasil gate konvergensi, kegagalan XOR dari sebuah
perceptron tunggal, dan prediksi XOR dua lapisan akhir.

**Tindakan berikutnya:** Jelaskan mengapa satu batas linear tidak dapat menyelesaikan XOR, lalu
lanjutkan ke [Jaringan Multi-Lapisan dan Forward Pass](02-multi-layer-networks/).
