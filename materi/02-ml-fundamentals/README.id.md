# Fase 2: Dasar-Dasar ML

> Pembelajaran mesin klasik masih menjadi tulang punggung sebagian besar AI produksi.

## Mulai fase ini di GitHub

**Prasyarat:** Fase 1 (Dasar Matematika dan NumPy). Periksa rute dengan
`python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route ml-foundations`.

**Pelajaran pertama:** [Apa Itu Pembelajaran Mesin](01-what-is-machine-learning/)

Jalankan perintah ini dari akar repositori:

```bash
python3 phases/02-ml-fundamentals/01-what-is-machine-learning/code/ml_intro.py
```

Simpan perintah, kode keluar, akurasi pengujian, baseline acak, dan satu kalimat
yang menjelaskan mengapa klasifikator yang dipelajari mengalahkan baseline itu.

**Tindakan berikutnya:** Ubah pemisah kelas, prediksi bagaimana akurasi akan bergerak,
jalankan lagi, lalu lanjut ke [Regresi Linear dari Awal](02-linear-regression/).

Jelajahi [daftar lengkap pelajaran Fase 2](../../docs/README.md#phase-2) atau
[peta jalan lintas fase](../../ROADMAP.md).
